# 星球翻翻碰

[在线试玩](https://guangli395.github.io/planet-pairs/) · [GitHub 源码](https://github.com/guangli395/planet-pairs)

手机竖屏 H5 可玩原型。TypeScript + Vite + Phaser 4.2.1，首页与弹窗采用 HTML/CSS，棋盘采用 Phaser。经典、萝卜、奶茶使用 SVG；奶娃使用已确认参考图裁切调色的透明 PNG 半身像与 SVG 鎏金卡背。

## 本地运行

```powershell
npm.cmd install
npm.cmd run dev
```

打开终端显示的地址，默认 http://localhost:5173/ 。手机与电脑在同一网络时，可打开终端显示的 Network 地址；需要电脑防火墙允许访问。游戏素材随项目提供，不依赖外部字体或图片服务。

```powershell
npm.cmd test
npm.cmd run build
```

构建文件位于 `dist/`。不要直接双击 HTML，应通过 HTTP 服务预览。

分享网页试玩见[网页试玩发布](docs/网页试玩发布.md)。已准备 GitHub Pages 自动构建发布配置；也可将 `release/planet-pairs-demo.zip` 解压后上传到静态网站托管服务。

首页与棋盘采用分包加载。生产版本新增首次资源准备页：提前缓存四套皮肤、拆包和棋盘，解析引擎并解码图片后进入首页；重复打开优先使用按版本保存的本地资源。开发服务跳过持久缓存。手机音效、动画优化及网站与小游戏包的区别见[手机加载缓存与音效优化](docs/手机加载缓存与音效优化.md)。国内托管的域名、区域和默认地址有效期限制见发布文档。

## 已实现

- 首页免费切换「经典宇宙 / 萝卜宇宙 / 奶茶宇宙 / 奶娃宇宙」，记住外观选择。萝卜宇宙采用奶油、杏橙和叶绿暖色界面，提供九种叶色的原创临时 SVG 萝卜；奶茶宇宙采用红白茶饮店配色，九种名称统一为伯牙、茉莉、拿铁、豆乳、糯米、波霸、三兄弟、烤奶、珍珠，杯身也使用对应简称；奶娃宇宙采用深色黑曜与香槟金界面，九色角色保留头部、肩膀、双臂及上半身，统一使用黑曜鎏金卡背。首页主图、幸运选择、棋盘与翻牌、卡背、祝福卡包和六张祝福插画、隐藏切包、飞行收集及奖励卡同步换肤。所有主题共用关卡、体力和纪录；换肤不保存当前对局。
- 首页闯关、无限双入口，两份榜单各有前三名展示位置。
- 开局顺序：拆开祝福包，免费翻开一张（看广告可任意选择）→ 幸运星球选择 → 选择 20/30/40/50 张起始牌。九种星球等概率。
- 九宫格发牌、翻面、横竖三连优先、全盘对碰、全家福免费加翻、清台奖励。
- 幸运立即返卡；满格或卡牌耗尽后统一结算。单次自动执行一轮，手动执行一张。
- 发牌从下方牌堆飞出，由小到大落入对应空格后翻面；收集飞到进度条后立即接下一组对碰或三连，奖励卡同时继续飞回牌堆。剩余数按返卡实际抵达逐张增加，整轮奖励结束后开放发牌。
- 主棋盘翻牌复用祝福卡的清脆和弦，关闭其中的破空噪声层，跟随现有静音开关；卡片落位不额外播放落地音，奖励返卡及其他事件使用原有音效。翻面采用 380 毫秒临时双面 3D 卡层，带轻微抬起、回弹、虹彩与扫光，落位后交还 Phaser；减少动态效果时使用短淡入。
- 闯关目标 50 起步，每关加 10；胜利后下一关重选祝福、重选幸运、重新开始。
- 闯关与无限共用体力，初始 10 点，每 10 分钟自然恢复 1 点至 10 点；每次创建新局消耗 1 点，暂停后继续不重复扣。
- 补体力入口的广告单独计数：前两次各 +5（允许超过自然上限），第三次当日无限体力并解锁当日 30 张档。北京时间零点结束无限体力、恢复至 10 点并重新锁定 30 张；普通体力跨日按时间恢复。
- 20 张直接使用体力；30 张当天解锁后直接使用体力；40/50 张分别完成 1/2 次选牌广告并消耗体力。选牌广告在本次准备过程中保留进度，40/50 档共享已完成次数；结束本局或刷新后重新计算。
- 启程赠礼在所选档位上额外 +20 张，即实际 40/50/60/70 张。
- 每次新开局进入棋盘，全部起始牌从棋盘上方星星处落入发牌处，剩余数量随抵达从 0 增长到本局总数；所有祝福和档位均播放。入堆使用原有奖励提示音并跟随静音开关，快速入堆时限制音效重叠；就位后开放发牌，继续当前对局不重播。
- 每局限一次广告续局 +10 张，保留棋盘和统计；选牌、续局广告均不计入补体力的三次进度。
- 对局与开局准备仅在当前页面内保留，不自动存档、不跨刷新恢复。返回首页先确认是否结束本局：确认则清空棋盘、卡数、祝福及准备进度；取消则关闭弹窗继续当前页面。体力、已通关关卡、个人纪录及音效设置继续保存在本机。
- 祝福触发时显示卡片柔光、祝福标识轻跳、奖励文字及星光；幸运奖励用小提示，其余祝福短暂显示在棋盘中央，音效跟随设置开关。
- 隐藏卡包按刀痕实际分割出的区域计数并裁切卡包原图：一刀两片，交叉两刀四片，重复刀痕不加片。切口贴在包身上，刀光短暂闪过后消退，结束时各块原图独立旋转散落，再发放奖励。每片奖励一包，奖励最多 30 包；未切开不发奖。快速划过卡包也能检测。

开发服务运行时，可打开 http://localhost:5173/tools/blessing-preview.html 逐一预览六种祝福的视觉效果。该页面使用独立规则样例，不读取对局存档，生产构建不包含这个开发页面。

祝福选择采用星际铝箔拆包：移植 MIT 开源项目 [prism-holo-pack](https://github.com/Lone3m-tech/prism-holo-pack) 的弹簧动画核心、96 段撕裂、12 段卷曲封条、32 道光流、粒子与程序化音效。封条撕断后袋体反冲下落，六张卡以背面出包、环绕落位。六种祝福各一张，顺序在当前准备中保持不变。免费只可翻开一张，满意即可下一步；点击带播放标识的“任意选择”，点击后剩余卡依次翻开，可任意改选。也可不免费翻牌，直接点击该按钮展开全部六种。已获得的选择权限与已翻结果仅在当前页面的本次开局保留，结束本局或刷新即清除，不影响补体力或起始牌广告计数。页面只保留标题、操作提示、所选祝福效果与按钮。独立预览位于 http://localhost:5173/tools/blessing-pack-preview.html ，不读写游戏存档。源码位于 `public/prism-blessing/`，许可见 `docs/licenses/prism-holo-pack.txt`。

开发时可打开 http://localhost:5173/?previewBlessing=1 从拆包进入完整开局流程；此模式使用临时内存存档，不会修改玩家进度，刷新即重置，生产构建不启用。

隐藏切包可通过 http://localhost:5173/?previewHidden=1 独立预览，不读写玩家存档。倒计时从首次点击或滑动开始；刷新可重复检查。

连续结算可通过 http://localhost:5173/?previewSettlement=1&previewUniverse=carrot 独立预览：一次三连、三次对碰、清台，最终收集 9 根萝卜、剩余 22 张；将 `carrot` 改为 `classic` 可检查经典主题。使用临时内存，不改动玩家进度，生产构建不启用。

## 当前边界

当前暂时跳过所有广告演示弹窗：点击广告按钮直接获得对应奖励。祝福任选、补体力、40/50 张起始牌与续局统一通过临时奖励入口；次数限制和各类计数仍保留。之后接平台广告时替换 `requestAdReward`，仅在有效完成回调后发奖。

广告按钮当前直接触发奖励，没有请求真实广告、不会产生收益。排行榜显示空位及本机纪录，尚未接入 TapTap 登录、头像、云端成绩或排行榜。没有充值功能。已有四套可切换皮肤；萝卜与奶茶采用代码绘制的 SVG 美术，奶茶插画不是官方商品照片；奶娃为参考图的本地裁切调色素材。

本机纪录不能替代服务器校验。后续采用 TapTap H5 小游戏路线，接入平台身份、排行榜与真实激励视频回调，并在平台容器和真机上验证兼容性。平台运行时提供 `tap` 排行榜接口；基础榜单服务与自定义玩法的成绩校验是两件事。广告奖励必须以平台的有效完成回调为准。官方要求、H5 与普通小游戏的区别及双榜实施建议见 [TapTap H5 接入调研](docs/TapTap-H5接入调研-2026-11-24.md)。

规则见 `docs/翻卡对对碰-游戏设计草案.md`。当前按已确认数值运行，未为提高通关率暗改概率；平衡模拟与后续调参建议见 `docs/技术选型与数值检查.md`。

## 文件位置

- `src/rules.ts`：独立规则与事件快照。
- `src/main.ts`：页面流程、动画调度、临时广告奖励入口。
- `src/bootstrap.ts`：首次加载页、资源预热与缓存降级；`tools/offline-build.ts`、`tools/service-worker.js`：发布资源清单与版本缓存。
- `src/settlement-playback.ts`：连续结算时追踪在途奖励，防止旧返卡回调覆盖新进度，等待整轮动画收尾。
- `src/themes.ts`、`src/themes.css`：宇宙注册表、主题资源与文案、界面配色。新增主题按九种规则编号配置，不复制玩法逻辑。
- `src/board.ts`：Phaser 棋盘与翻卡。
- `src/card-flip.ts`、`src/card-flip.css`：主棋盘与额外卡的双面 3D 翻牌演出。
- `src/card-sounds.ts`：复用 `public/prism-blessing/sound.js` 的翻牌音效。
- `src/hidden-slices.ts`：隐藏切包的刀线裁剪与分片计数。
- `src/hidden-pack.ts`、`src/hidden-pack.css`：使用同一组多边形裁切包身、绘制表面切口、短暂刀光和碎片散落，所有皮肤共用。效果与验收见[隐藏卡包实际切割](docs/隐藏卡包实际切割验收.md)。
- `src/store.ts`：体力、纪录、音效与宇宙外观设置的本地保存，以及旧数据迁移；不保存对局和开局准备。
- `src/energy.ts`：体力恢复、跨日、补体力奖励与卡数档位的广告要求。
- `public/assets/`：经典星球与卡背；`carrot/`、`milktea/` 分别包含九款角色、卡背、隐藏包及九宫格预览。运行 `node tools/generate-carrot-assets.mjs` 或 `node tools/generate-milktea-assets.mjs` 可重新生成对应素材。
- `public/assets/naiwa/`：九张透明 PNG 半身像、统一鎏金卡背与隐藏包；`tools/generate-naiwa-assets.py` 从已确认的 `docs/designs/naiwa-concept-v2/` 导出，需 Pillow、NumPy。
- `tests/rules.test.ts`：结算优先级、返卡、胜利、概率区间、卡牌守恒等验证。
- `tests/themes.test.ts`：主题资源完整性、嵌套目录 iframe URL、偏好迁移及不保存对局。

后续添加皮肤请先看[新增皮肤接入指南](docs/新增皮肤接入指南.md)，包含素材要求、注册配置、iframe 同步、已知限制和验收清单。现有换肤验收见[宇宙换肤验收](docs/宇宙换肤验收.md)。开发时可用 `?previewUniverse=carrot` 或 `?previewUniverse=classic` 进入独立内存预览；可与 `previewHidden=1` 组合检查对应隐藏卡包。预览不读写玩家数据，生产构建不启用。

奶茶皮肤的单品清单、美术来源与检查结果见[奶茶宇宙设计与验收](docs/奶茶宇宙设计与验收.md)，独立预览使用 `?previewUniverse=milktea`。

奶娃皮肤的材质方案、资源来源与检查结果见[奶娃宇宙设计与验收](docs/奶娃宇宙设计与验收.md)，独立预览使用 `?previewUniverse=naiwa`。
