# 隐藏卡包实际切割验收

2026-11-24。将原先覆盖在卡包前方的长期刀线，改为包身原图的真实多边形分片。

## 表现与规则

每次有效划动复用 `HiddenSlices` 算出的区域裁切当前主题包图。横切一刀生成两块，交叉两刀生成四块，斜切沿实际方向分割；重复刀线不会新增碎片。显示的片数、渲染的图像块和奖励使用同一份几何结果。

刀光是约 260ms 的短暂挥刀效果；较细的切口位于包图自身坐标内，并用原图透明轮廓约束。结束后切口和刀光消退，各片从原位置分别移开、旋转并下落淡出，约 1.1 秒后继续发放奖励。系统减少动态效果时使用短淡出，保留同样的计数和奖励。

切割检测忽略包图外侧少量透明留白，几何裁切仍用完整图片坐标，避免出现看不见的碎片或切口错位。三秒切割时间、每片一包及最多 30 包奖励继续沿用。

奶娃隐藏包同步改成黑曜鎏金铝箔封装袋：热封压纹、侧折、袋身高光、折角与奶娃主图印刷。卡片的统一线刻卡背不变。

## 实现与参考

- `src/hidden-slices.ts` 提供独立几何快照，外部绘图不能修改后续计数。
- `src/hidden-pack.ts` / `src/hidden-pack.css` 将当前主题图像裁成实际区域，并处理包身切口、短暂刀光、散落及清理。
- `src/main.ts` 在计时结束后等待碎片动画完成，再返回既有奖励流程。
- `tools/generate-naiwa-assets.py` 保存奶娃箔袋源设计；PNG 主图直接内嵌到 SVG，确保 SVG 作为图片及透明遮罩时仍能正常显示。

网络参考：[Fruit Slice · Reactive CSS](https://codepen.io/editor/Maseone/pen/01a19dbd-3728-7821-a826-7f3286e31471?show=preview&panel=false) 的分片分离思路，以及 [MDN clip-path](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/clip-path) 的多边形图像裁切。实现沿用本项目已有切割几何，无新增动画库依赖。

## 验收

- `npm.cmd test`：45 项通过。新增检查保证所有碎片总面积覆盖整张包图，每块都位于历次刀线的一侧；几何快照不会污染规则状态。一刀两片、交叉四片、重复刀线及奖励上限的原有测试通过。
- `npm.cmd run build`：通过，保留原有 Phaser 主包体积提示。
- 浏览器实际拖动验证奶娃 390×844、经典/萝卜/奶茶 320×640。经典交叉斜切为四块，萝卜横切为两块，奶茶与奶娃横竖交叉为四块，结束奖励分别为 4/2/4/4 包。
- 快速连续五条横线、四条竖线，实际片数依次为 2、3、4、5、6、12、18、24、30。30 个图像块对应 30 包奖励，达到上限后继续划动不再增加。
- 仅划过透明边缘计数为 0，无奖励，挑战正常结束。
- 散落时刀光节点已移除、表面切口透明度为 0；结束后没有挑战层、图像碎片或刀光残留。检查的独立切包预览日志无错误或警告。
- 对局入口也已进入发牌后的隐藏挑战并返回游戏，页面显示隐藏款奖励 30 张、剩余 41 张，发牌按钮恢复可用。
- 新奶娃封装袋再次验证一刀两块、交叉四块、散落、4 包奖励及节点清理，嵌入主图正常显示。

以上为桌面浏览器与手机尺寸模拟，未补真实手机及系统减少动态效果开关的现场验收。
