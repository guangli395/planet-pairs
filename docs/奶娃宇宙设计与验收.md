# 奶娃宇宙设计与验收

2026-11-24。已作为第四套皮肤接入，ID 为 `naiwa`，首页免费切换并记住偏好。

## 已确认的视觉方案

- 沿用经典宇宙的深色布局，改为黑曜、深蓝灰与香槟金。首页、准备页、棋盘、弹窗、隐藏包和奖励提示统一处理。
- 九色奶娃使用已确认的半身比例，保留头部、肩膀、双臂、双手及上半身。黄奶娃保留原黄色，其他款直接换色，保留明暗、皮肤纹理、绿色眼睛和嘴线。
- 名称依次为黄奶娃、红奶娃、紫奶娃、蓝奶娃、绿奶娃、粉奶娃、橙奶娃、青奶娃、白奶娃。
- 统一黑曜鎏金卡背采用双层金属压边、细纹、金粉点与线刻侧脸。未翻开的祝福卡背图、侧边、光晕和阴影一致；不同角色颜色仅在正面揭晓。
- 祝福包保留原版撕裂、金属薄膜、彩虹喷流、出卡弹簧与翻面演出。正面采用深色铭牌、金色压边、全息虹彩、镜面扫光与浮出卡面的角色。
- 棋盘卡面采用深色三段渐变、双道鎏金细边和弱角色色柔光，翻面继续使用现有 380ms 演出，扫光改为香槟金。奖励提示使用金色星屑、光环与深色铭牌。

## 素材和接入位置

用户参考图的永久副本与已确认讨论稿位于 `docs/designs/naiwa-concept-v2/`。这些素材为本地裁切、调色和排版，未调用 AI 生成服务。

`tools/generate-naiwa-assets.py` 使用 Pillow、NumPy 从 `bust-0.png` 至 `bust-8.png` 导出：

| 输出 | 用途 |
| --- | --- |
| `public/assets/naiwa/naiwa-0.png` 至 `naiwa-8.png` | 384×384 透明 RGBA 半身像，清除白底 JPEG 压缩残影并处理透明边缘 |
| `public/assets/naiwa/cardback.svg` | 全流程共用黑曜鎏金卡背 |
| `public/assets/naiwa/hidden-pack.svg` | 隐藏切包封面 |
| `public/assets/naiwa/preview.jpg` | 九色素材预览，不参与运行时预加载 |

主题配置在 `src/themes.ts`；`material: 'gilded'` 传入棋盘与祝福 iframe，`blessingCharacters: [0,1,2,3,4,5]` 让拆包插画和祝福介绍一致。新字段均可选，保留旧主题的默认行为。

主页面样式在 `src/themes.css`，iframe 样式在 `public/prism-blessing/integration.css`，卡框材质在 `cards-config.js` 和 `src/board.ts`。规则编号仍为 0～8，皮肤共用规则、体力、关卡与纪录。

## 验收结果

- `npm.cmd test`：43 项全部通过。资源检查覆盖四套主题，并支持 PNG 签名、IHDR 尺寸与 RGBA 通道；验证奶娃 iframe 资源在嵌套部署目录下仍使用正确绝对 URL。
- `npm.cmd run build`：通过。Vite 仍提示 Phaser 主包大于 500kB，该提示为已有打包体积问题。
- 浏览器检查 390×844、320×640；窄屏没有横向溢出，已修正首页装饰图压住副标题的问题。四张皮肤卡保持相同尺寸，320 小屏列表可滚至最后一行。本轮对后续隐藏标签设置桌面尺寸时实际视口仍为 320，不能将该截图当作已完成桌面宽屏验收。
- 祝福包拆开后六张全为背面；免费翻开后只有一张正面，其余锁定；再点广告任选会依次翻开剩余卡。直接点广告任选也会翻开全部六张，沿用当前直接奖励约定。
- 六张卡背的背景 URL、侧边色与阴影计算值一致，九色 PNG 和六张祝福图均加载成功。320 小屏喷流可延伸到整页上方。
- 双重心愿可选黄奶娃和白奶娃，起始牌与游戏 HUD 显示一致；20 张正常进入对局，手动单张与自动整轮均可完成，棋盘与飞卡使用当前皮肤。
- 连续结算场景包含三连、三组对碰和清台，最终收集 **9 只奶娃、剩余 22 张**，按钮恢复可用，没有残留奖励层、飞卡或翻牌层。
- 隐藏切包封面与背景正确。切割规则沿用已有测试，一刀两片与交叉四片测试通过。
- 经典→萝卜→奶茶→奶娃往返时，标题、主图、按钮配色均正确。生产构建普通入口切换至奶娃并刷新后仍记住皮肤，体力与纪录保持；验收后恢复原外观偏好。
- 主游戏页与生产入口读取的错误/警告日志为空。后续祝福 iframe 切换过程中记录到一条 `MutationObserver.observe` 的参数类型错误；项目与上游拆包源码未找到该调用，现有日志没有来源堆栈，暂不能确定来源。出现后六卡全开、祝福介绍、返回首页及换肤仍正常，没有缺图。保留该日志线索，不能声称全部控制台均无错误。音效实现和静音开关沿用现有入口，没有新增落地音。

### 图文与收集栏对齐修正

修正祝福介绍中 30px 图标容器容纳 34px 图片的问题：改为 40px 固定图标列与可收缩文字列，列间距 12px，图像完整居中，说明文字在剩余宽度内换行。收集栏将标签、数值和单位改为共享文字基线，并统一数值与单位的间距。

复查 390×844 与 320×640；四套皮肤的六项介绍均无横向溢出，图片全部位于容器内。奶娃连续结算完成后仍为收集 9、剩余 22 张。生产构建通过。修正截图：[祝福介绍](screenshots/naiwa-guide-aligned-390.jpg)、[窄屏介绍](screenshots/naiwa-guide-aligned-320.jpg)、[收集栏](screenshots/naiwa-score-baseline-390.jpg)。

### 隐藏包封装与真实分片修正

隐藏包改为铝箔封装袋：上下热封压纹、侧边折痕、鼓起的袋身高光和奶娃主图印刷，去掉原先与卡背相似的内框线刻构图。统一黑曜鎏金卡背继续用于卡片背面。

切割时直接裁开当前包图，切口受图片透明轮廓限制；结束时刀光消退，各块图像按真实刀线分离并旋转散落。共享四套皮肤，详见[实际切割验收](隐藏卡包实际切割验收.md)。[新封装袋](screenshots/naiwa-hidden-foil-pouch.jpg)、[切开四片](screenshots/hidden-real-four-pieces-cut.jpg)、[四片散落](screenshots/hidden-real-four-pieces-scatter.jpg)。
