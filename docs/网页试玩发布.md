# 网页试玩发布

2026-11-24。当前游戏可以部署为静态网站，不需要游戏服务器。四套皮肤、拆包、切包、音效与游戏规则均包含在构建产物中，朋友用手机或电脑打开 HTTPS 链接即可试玩。

## GitHub Pages

适合持续更新：推送代码后自动测试、构建并发布。GitHub Free 的 Pages 通常用于公开仓库，源码也会公开；私有仓库的 Pages 可用性取决于账号套餐。

已准备 `.github/workflows/pages.yml`，监听 `main` 分支。工作流使用 Node.js 24、`npm ci`、测试、Vite 构建，再发布 `dist/`。项目已有 `base: './'`，祝福 iframe、皮肤与音效均采用部署目录相对路径，适配 `https://用户名.github.io/仓库名/`。

本项目已连接公开仓库 [guangli395/planet-pairs](https://github.com/guangli395/planet-pairs)，本地默认分支为 `main`，远程名为 `origin`。试玩地址为 [guangli395.github.io/planet-pairs](https://guangli395.github.io/planet-pairs/)。自行迁移或首次配置其他仓库时：

1. 在 GitHub 建立用于试玩的仓库，例如 `planet-pairs`，默认分支使用 `main`。
2. 用 GitHub Desktop 把本地 `D:\youxi` 创建为仓库并发布，或通过 Git 命令提交并推送到目标仓库。已有 `.gitignore` 会排除 `node_modules/`、`dist/`、本地试玩压缩包和日志。
3. 仓库进入 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
4. 在 **Actions → Publish playable demo** 手动运行一次，或继续推送一次 `main`。成功后，部署结果会显示网站地址。
5. 用手机打开地址，走一遍首页换肤、祝福拆包、新开局与发牌，再把普通首页地址发给朋友。

以后只需把更新后的源代码推送到 `main`，工作流会重新发布。GitHub 官方 CLI 已安装在本机 Codex 工具目录；访问使用现有 Git Credential Manager 登录状态。

参考：[GitHub Pages 官方介绍](https://docs.github.com/en/pages/getting-started-with-github-pages/about-github-pages)、[官方静态网站发布工作流](https://github.com/actions/starter-workflows/blob/main/pages/static.yml)。

## 先快速分享试玩链接

`release/planet-pairs-demo.zip` 是可直接托管的构建文件，解压后根目录包含 `index.html`、`assets/`、`prism-blessing/` 等。它不包含 `src/`、`tests/` 等原始工程目录、开发文档或 `node_modules/`，也不包含玩家本地数据；浏览器运行所需的 JavaScript 与资源随站点提供。

可以使用 [Netlify Drop](https://app.netlify.com/drop)：登录后，把解压得到、内部含 `index.html` 的目录上传，平台会给出可分享的 HTTPS 地址。它属于海外托管方案，不能承诺解决中国大陆访问速度问题。也可把相同文件交给支持静态文件上传的网站托管服务。不要直接上传整个开发文件夹，也不要通过双击本地 HTML 验收。

重新打包时先运行 `npm.cmd run build`；压缩的是 **`dist/` 里面的内容**，确保解压后的站点根目录直接就是 `index.html`。

## 试玩版本的行为

朋友首次打开会进入普通首页，自行切换宇宙；开发用的 `previewOpening`、`previewBlessing` 等预览参数在生产构建不生效。

体力、关卡纪录、音效和皮肤偏好保存在各自浏览器中，对局不跨刷新恢复。排行榜暂时显示本机纪录及空位，广告入口仍按当前约定直接发奖。部署网站不会自动接入 TapTap 账号、全球排行榜或真实广告。

GitHub Pages 的访问速度可能受朋友所在网络影响，分享前用他们实际使用的手机网络打开检查。正式面向国内长期运营时，再选择相应地区的托管、域名和平台接入方案。

## 中国大陆访问与首页加载优化

GitHub Pages 保留为源码自动发布及备用试玩入口。当前已将 Phaser 棋盘从首页脚本拆出：首页入口 JavaScript 由约 1.44 MB 降为约 71 KB（gzip 约 384 KB 降为约 25 KB）。进入祝福准备流程后才后台加载约 1.37 MB 的棋盘模块；正式进入棋盘时等待其准备完成。加载失败可原地重试，不额外扣体力。此改动减少首页等待，不代表解决跨境网络线路问题；实际效果需以朋友的大陆手机网络为准。

已核对 2026-11-24 官方说明：

| 平台 | 默认域名与长期分享限制 |
| --- | --- |
| 腾讯 EdgeOne Makers（原 Pages） | 大陆访问项目/部署默认域名需系统生成的预览链接，有效期 3 小时；长期分享建议自定义域名。大陆或全球含大陆节点要求域名备案；全球不含大陆节点不要求备案，但仍需实际网络测速 |
| 阿里云 ESA Pages | 公共测试域名需鉴权 token，有效期 60 分钟；长期分享需绑定已接入 ESA 的自定义域名 |
| EdgeOne 匿名部署 | 无需账号可创建短期预览，但项目需 60 分钟内认领，否则自动删除，且预览有访问人数/IP 限制，不能作为持续对外试玩地址 |

因此不能把另一个默认测试域名直接当作稳定的国内试玩站。推荐先确认可用的腾讯云或阿里云账号及域名：有备案域名可选择大陆节点；无备案域名可评估香港或全球不含大陆节点。正式迁移前还需要账号登录和目标域名，当前未开通任何收费套餐、未购买域名，也未更改现有 DNS。

官方参考：[EdgeOne 域名与区域](https://pages.edgeone.ai/document/domain-overview)、[EdgeOne CLI 与匿名部署限制](https://pages.edgeone.ai/document/edgeone-cli)、[阿里云 Pages 公共域名限制](https://help.aliyun.com/zh/edge-security-acceleration/esa/user-guide/create-pages-by-cli)。
