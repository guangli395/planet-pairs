# 开局入堆动画修复

2026-11-24。修复进入棋盘后，起始牌从星星处落入下方发牌按钮的动画只在部分开局出现的问题。

## 原因与修改

原实现只在「启程赠礼」分支播放 +20 返卡动画，其他祝福直接显示起始牌数量。现在每次新创建的对局进入棋盘时，都播放本局全部起始牌的入堆动画，赠礼仍显示额外 +20 的祝福提示。

初次创建 Phaser 棋盘期间，先把展示数量设为 0，避免旧模板数字先闪现；棋盘完成布局并画出首帧后，从 `.board-jewel` 星星处向发牌按钮飞卡。图片完成解码后才开始飞行，等待解码期间保持隐藏。卡牌抵达后逐张更新展示数，演出结束后显示规则中已确定的完整卡数并开放操作。

起始牌在约一秒内依次起飞，最后一张约 1.4 秒抵达，70 张也不会逐张拖成长等待。新开局使用原有奖励音，跟随当前静音开关；密集抵达时按约 100ms 限制播放，最后一张保留到达提示。棋盘内的发牌、翻面与落地声音约定继续沿用。

`WeakSet<Run>` 标记已播放的对局，并检查 `started` 状态；暂停后继续当前对局不重播。规则中的卡数不因展示动画重复增加；动画失败会等待其余飞卡收尾，再恢复完整数量与按钮状态。

## 验证

- `npm.cmd test`：45 项通过。
- `npm.cmd run build`：通过，仍有已有的 Phaser 主包体积提示。
- 浏览器 13 个独立开局场景：六种祝福配基础 20 张；普通祝福 30/40/50 张；赠礼 50+20=70 张；经典、萝卜、奶茶各一次普通 20 张。所有场景均观察到飞卡，图像完整加载，动画中发牌按钮锁定。
- 13 个场景的展示数字均从 0 单调增加，最终为 20/30/40/50/70 等对应总数；结束没有飞卡或奖励提示残留。
- 暂停后继续没有新增入堆飞卡、没有增加卡数。入堆过程中关闭音效，按钮正确显示「开启音效」，动画及最终 20 张正常完成；音效调用实时读取同一个静音设置。
- 正常祝福准备流程也已进入棋盘并完成发牌、对碰，页面恢复可继续发牌。独立开局预览读取的错误/警告日志为空。
