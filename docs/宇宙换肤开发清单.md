# 宇宙换肤开发清单

更新日期：2026-11-24。两套宇宙换肤已实现，验收结果见《宇宙换肤验收.md》。

本文保留首批两套宇宙的开发约定与实施顺序。后续新增皮肤请使用[新增皮肤接入指南](新增皮肤接入指南.md)，其中包含当前代码的接口、素材要求、限制和逐项验收流程。

## 已确定的方向

- 排行榜暂缓，优先制作宇宙换肤功能。
- 当前主题命名为「经典宇宙」，新增主题命名为「萝卜宇宙」。
- 萝卜角色数量与现有星球一致，共九种；用不同颜色的叶子区分，绿叶款叫「绿萝卜星球」。
- 造型参考胖短、圆润、大眼睛、可爱的胡萝卜气质，统一画风与比例。
- 萝卜首版采用代码绘制的 SVG 作为临时角色素材，之后可替换为透明 PNG/WebP；制作方式不限制后续皮肤的素材来源。
- 首页增加简洁的「切换宇宙」入口，保留现有页面的主要结构，避免增加说明小字。

## 已采用方案

- 九种萝卜均为橙色身体，主要改变叶色。暂定绿、粉、紫、蓝、黄、红、橙、青、白九款，具体颜色随实图调整辨识度。
- 两个宇宙是外观主题，共用关卡、体力和个人纪录，九种角色的概率、配对、幸运、祝福及奖励规则一致。
- 只在首页切换宇宙，当前对局中不增加切换入口。
- 记住宇宙选择，作为与音效类似的外观设置；不保存或恢复正在进行的对局。
- 经典宇宙默认选中，旧的玩家数据不含宇宙字段时正常回退。

## 开发顺序

1. **制作临时角色素材**
   - 先画绿叶萝卜母版，检查在当前小卡面上的比例、表情和辨识度。
   - 基于同一母版完成另外八种叶色，统一画布、留白、朝向、阴影和光照。
   - 输出九种透明背景 SVG 及一张九宫格预览，便于整体检查。
   - 角色图与名称分开管理，图片内不绘制文字。
2. **抽出宇宙主题配置**
   - 保留规则中的数字角色编号，统一配置每个宇宙的九种名称、图片、强调色、卡背和卡包资源。
   - 集中管理资源路径，避免在首页、棋盘和祝福 iframe 中分别写死。
   - 图片接口兼容 SVG、PNG 和 WebP，后续替换美术时直接更换资源配置。
3. **设计首页与切换弹窗**
   - 游戏标题下放紧凑的「经典宇宙 ▾」或「萝卜宇宙 ▾」入口。
   - 点击后显示两张主题预览卡，分别使用星环星球和绿叶萝卜作为主角。
   - 清晰标明「使用中」，另一张显示切换操作；采用短淡入反馈。
   - 按已确认的免费切换与整套暖色方案完成萝卜主题交互。
4. **全流程接入换肤**
   - 首页主角、幸运角色选择、起始牌预览、棋盘卡面、幸运标识、额外翻牌、收集与返卡动画同步使用主题资源。
   - 卡背、隐藏卡包及祝福卡包封面/六张祝福卡插画同步处理；祝福仍为六种。
   - 向祝福 iframe 传入主题配置，避免拆包界面残留经典星球。
   - 切换时更新 Phaser 纹理和翻牌合成图缓存，避免换回主题后串图。
5. **核验与交付**
   - 检查经典→萝卜→经典反复切换、刷新记忆及旧数据迁移。
   - 检查九种角色、幸运选择、拆包、六张祝福卡、隐藏切包、主棋盘翻面及飞行动画。
   - 检查窄屏、小卡面辨识度、按钮触控和加载失败回退。
   - 运行现有规则测试与生产构建；必要时补主题设置迁移和资源完整性检查。
   - 保存首页、主题弹窗、萝卜棋盘及九色素材预览截图。

## 用户最终确认

1. **解锁方式**：两个宇宙免费切换，不使用广告解锁。
2. **配色范围**：萝卜宇宙整套采用暖色调，不追求神秘星空；已采用奶油白、杏橙与叶绿。经典主题保留原有表现。
3. **完整替换**：首页主打图、祝福卡包及其他所有角色/卡片展示位置跟随当前皮肤。
4. **后续扩展**：统一配置主题资源、名称、文案、界面与棋盘颜色，供之后增加其他皮肤。

以上内容已按用户确认实施，原先的深色萝卜方案未采用。
