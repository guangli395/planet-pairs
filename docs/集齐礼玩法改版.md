# 集齐礼玩法改版

日期：2026-11-28。替代旧版「全家福免费加翻」及「清场礼赞」。四个宇宙共用规则。

祝福名称已简化为「幸运双倍、双重幸运、开局奖励、对碰三次奖励、三连奖励、集齐奖励」，内部 ID 与效果数值保持原样；下方截图为改名前的演出记录。

## 当前规则

| 事件 | 条件 | 收集进度 | 返卡 |
| --- | --- | --- | --- |
| 对碰 | 两张相同 | +2 | +1，对碰三次奖励按真实对碰次数叠加 |
| 三连 | 横排或竖列三张相同，优先于对碰 | +3 | +2，三连奖励额外 +1 |
| 集齐礼 | 九格填满，九种各一张 | +9，九张全部收走 | +5，已含清台奖 |
| 集齐奖励 | 装备此祝福并触发集齐礼 | 同上 | 在 +5 上额外 +2，共 +7 |
| 普通清台 | 对碰、三连将有卡棋盘清空 | 已在消除时计入 | 额外 +5，集齐奖励不增强普通清台 |

仍然先横三连、竖三连，再全盘对碰。只有九格都没有相同类型时才触发集齐礼；有重复的满盘照常消除。耗尽时不足九种不触发集齐礼。

集齐礼取消额外随机翻卡，不扣待发卡数，不增加总翻牌数，不产生额外幸运返卡；不计为一次对碰或三连，不推进对碰三次奖励。原九张各计一次收集；达标时正常通关，事件快照包含最终棋盘和奖励。九种角色与六种祝福的概率不变。

祝福的内部 ID 保留为 `clear`，避免影响现有祝福卡包顺序、插画映射及皮肤配置；名称、说明和触发条件已统一更新。普通对局与准备阶段不新增持久存档。

## 演出与验收

九格一起亮起，九张同时向上飞入收集区域；中央显示「集齐礼 +5 张」，携带祝福时显示「集齐奖励 · +7 张」。奖励卡逐张落入牌堆，跟随原音效开关；用现有轻量星光与光环，不引入视频或新素材依赖。

开发预览仅在开发模式有效，使用临时内存，不读写玩家进度：

- `?previewUniverse=naiwa&previewCollection=1`：收集 9，剩余 11→16。
- `?previewUniverse=naiwa&previewCollection=clear`：收集 9，剩余 11→18。
- 加 `collectionWin=1`：从收集 45 触发到 54，检查通关状态；预览不会自动弹出结算窗口。
- `?previewUniverse=carrot&previewSettlement=1`：回归三连、三个对碰和普通清台，收集 9，剩余 11→22。

将 `previewUniverse` 改为 `classic`、`carrot`、`milktea` 或 `naiwa` 可检查四套皮肤。发布版按正常开局流程触发。

规则测试覆盖一次发奖、祝福合计 +7、普通清台不叠加、九张收集守恒、无额外随机抽卡、对碰次数不变、重复类型优先消除、耗尽未满不触发，以及集齐达标通关。在途返卡测试覆盖 +5/+7 逐张抵达，防止剩余数重复累计。

2026-11-28 本机验证通过：

- `npm.cmd test`：59 项通过，其中包含六种祝福各 40 局的带种子完整挑战。
- `npm.cmd run build`：类型检查与生产构建通过。
- Chrome 手机尺寸模拟：390×844、3 倍像素密度，四套皮肤各验证普通集齐与祝福集齐；另外验证实际发牌凑齐九种、普通连续结算、集齐达标及静音/减少动态，共 13 组，无页面异常或动画残留。这是浏览器模拟，未代替实体手机测试。
- 发布产物完整流程：首页玩法说明 → 拆包 → 广告任选 → 选择集齐奖励 → 幸运选择 → 起始牌入堆 → 实际发牌。卡面、所选说明、棋盘标识和祝福提示均显示新名称与效果。
