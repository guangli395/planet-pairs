# 奶娃宇宙风格讨论稿

日期：2026-11-24。当前交付为视觉提案，未注册新主题、未修改游戏流程。

网络查证：这类形象通常称为「奶蛙」，与用户提供的圆头、绿色大眼、扁嘴参考相符。主题名按用户用词保留「奶娃宇宙」。参考：[奶蛙词条及图册](https://baike.baidu.com/item/%E5%A5%B6%E8%9B%99/69649754)。网络图仅用于核对特征，没有下载用作交付素材。

效果稿 `naiwa-style-board.jpg` / `.png` 使用用户第三张参考图进行头部裁切、背景去除和九色调色；保留绿色眼睛和原有光照。主打奶黄，其余为樱粉、葡萄、雾蓝、薄荷、珊瑚、蜜橘、青柠、珍珠。表情和朝向先统一，便于讨论轮廓及颜色。

建议界面为奶油白与鼠尾草绿，卡面采用细纸纹、圆角、双层细边与柔和投影。卡背提供两种效果：深色细砂底加香槟金微浮雕轮廓；奶油纸底加深墨色压纹。推荐深色方案，所有角色共用相同卡背，不显示角色身份色。

本稿为本地参考图编辑与排版，并非 AI 生成。当前工具列表无内置生图工具，也未调用需要 API 密钥的生成服务。头部 PNG 为讨论阶段裁切图，正式接入前应按用户选定方向进一步修整轮廓、对比小卡尺寸与完善导出。

源脚本：`tools/design-naiwa-concept.py`，使用 Pillow / NumPy。参考头部副本保存在本目录 `reference-head.jpg`，脚本优先读取该文件，避免依赖临时附件路径。输出的九张头部、两张卡背以及整版讨论稿均在本目录。
