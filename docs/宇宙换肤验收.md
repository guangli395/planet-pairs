# 宇宙换肤实施与验收

日期：2026-11-24。

本文记录经典与萝卜的首批接入。新增第三套皮肤的完整清单见[奶茶宇宙设计与验收](奶茶宇宙设计与验收.md)。

## 已实现

- 首页标题下提供「经典宇宙 / 萝卜宇宙」切换入口，弹窗预览两套主题，免费切换并标明使用中。
- 萝卜宇宙为暖色风格：奶油白背景、杏橙主按钮、叶绿副按钮、浅色棋盘；不使用神秘星空背景与轨道装饰。
- 九款原创临时 SVG 萝卜共用橙色身体与表情，以绿、粉、紫、蓝、黄、红、橙、青、白叶色区分，保留用户指定的「绿萝卜星球」命名。
- 全部主题内容同步：首页与桌面主角、页面标题、幸运选择、棋盘卡图/名称、翻面卡背、卡堆、飞行收集、奖励卡、免费加翻、祝福包封面与六张祝福卡、介绍插图、隐藏包及切包挑战。
- 现有九种规则编号、六种祝福、体力、广告计次、关卡及纪录共用；宇宙偏好是永久外观设置，对局与开局准备仍不自动存档。
- 测试页面 `?previewUniverse=carrot` 使用独立内存；与 `previewHidden=1` 组合可预览萝卜隐藏切包。

## 扩展方式

完整的新增步骤、素材规范、已知限制和验收清单见[新增皮肤接入指南](新增皮肤接入指南.md)。以下为接口概览。

1. 在 `src/themes.ts` 的 `UNIVERSES` 注册一份 `UniverseTheme`，指定唯一 ID、九种角色（名称/图片/颜色）、主角编号、卡背与隐藏包。
2. 配置文案、网页颜色 token、棋盘颜色和祝福包材质。可复用 `night` 或 `warm` 配色规则；需要全新界面基调时扩展 palette 并增加对应 CSS。
3. 素材支持 SVG、PNG、WebP，规则模块不依赖文件格式。统一尺寸与透明留白，以便沿用卡面布局。
4. 祝福 iframe 由父页面传入绝对资源 URL，无需在 iframe 再维护一份皮肤名单。
5. Phaser 的纹理按主题 ID 隔离，切换开局时重画棋盘并清空翻面合成缓存；避免经典与萝卜互相串图。
6. 未识别的旧皮肤 ID 回退经典宇宙，并保留体力、关卡及纪录。

## 奖励提示修正

在独立预览 `tools/blessing-preview.html?theme=carrot` 验证了普通幸运、对碰及全部六种祝福；对应的背景渐变、文字阴影和图标滤镜均已正确覆盖。经典主题仍使用原有表现，生产构建通过。截图：`carrot-lucky-reward-fixed.jpg`、`carrot-pair-reward-fixed.jpg`。

## 连续结算衔接

对碰、三连的收集飞到上方进度区域后，立即开始下一组；上一组奖励卡的生成及返牌与下一组收集同时播放。中央结算提示按收集节奏缩短，避免文字互相遮挡。整轮奖励抵达前保持操作禁用，返卡按实际抵达逐张更新剩余数，并始终使用最新收集进度。

新增独立预览 `?previewSettlement=1&previewUniverse=carrot`，也支持 `classic`，不读写玩家数据。样例按三连、三个对碰、清台结算，剩余 11→22，收集 0→3→5→7→9。

本次 43 项测试及生产构建通过，新增验证覆盖多组返卡交错抵达、旧回调不回退进度、奖励守恒与动画失败时等待其余任务完成。浏览器确认经典、萝卜两套主题均同时出现收集与返卡，返卡期间按钮保持禁用，最终无残留飞行卡或特效，剩余 22 张后恢复发牌。控制台未报告错误或警告。截图：`settlement-overlap-carrot.jpg`、`settlement-finished-carrot.jpg`、`settlement-finished-classic.jpg`；时序记录：`settlement-classic-timeline.json`。

## 拆包彩带覆盖整个上方

原彩虹光流被拆包 iframe 的边界裁切，在标题下方形成水平截断线。现将实际 SVG 彩带挂载到父页面的整页特效层，保持原有弹簧、32 道光流、渐变与发光；卡包和六张卡仍在原窗口中运行。原引擎根据父页面传入的顶部及侧边空间延长光流，布局变化时同步位置与尺寸。标题和按钮在特效上方，特效不接收点击。

验证：生产构建、脚本语法检查和 43 项测试通过。390×844 经典主题下，32 道光流可延伸至页面顶部及左右边缘；原窗口顶边约为 150px，光流上缘可越过 0px，横向范围覆盖 0～390px。320×640 奶茶主题和独立拆包预览也显示完整光流，无横向页面溢出。

免费翻牌与下一步正常，进入幸运选择后特效层和 iframe 均被移除；返回已开祝福包时仍保留原选择，彩带隐藏。独立预览重置后只有一个特效层与 32 道光流，没有重复挂载。自动化日志仍可见此前已记录的 `MutationObserver.observe` 提示，实际演出和交互均完成；未将其作为新增功能的游戏故障。

截图：`blessing-ribbons-full-top-classic.jpg`、`blessing-ribbons-full-top-milktea-320.jpg`、`blessing-ribbons-full-top-standalone.jpg`，位于 `docs/screenshots/`。

脚本语法检查及生产构建通过。按反馈截图的 1018×901 尺寸检查，六张背面的基础角度分别为 -1.8°、0°、+1.8°，上下排一致；上排免费翻开一张后保持正常选中姿态，其余五张仍为背面，下一步可用。截图：`blessing-card-rows-matching-angles.jpg`。
