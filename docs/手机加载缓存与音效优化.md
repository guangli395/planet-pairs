# 手机加载、缓存与拆包优化

2026-11-24。对应手机试玩反馈：首次等待长、撕包和滑过卡背无声、拆包和六卡任选卡顿。

## 加载与本地资源

生产版本先显示轻量加载页，按资源字节数显示进度。准备首页、四套皮肤、祝福 iframe、音效合成脚本与 Phaser 棋盘模块，随后提前解析引擎并解码图片，再进入首页。首次仍需要网络；进度表示当前准备的资源量，不是预计剩余时间。

支持 Service Worker 的 HTTPS 浏览器会将游戏文件保存到本站专用 Cache Storage。相同版本再次进入优先读取缓存；构建时按内容生成版本，更新后准备新版本，保留前一版资源供尚未关闭的旧页面使用。只缓存发布资源，不保存正在进行的对局或准备流程，不改变现有体力、纪录和设置的存储规则。

等待较长时提供「重新加载」和「先进入游戏」，失败后可重试并复用已准备好的资源。平台容器若禁用 Service Worker，则退回普通资源预加载；此时持久缓存由浏览器 HTTP 缓存或平台包缓存决定，不能保证与独立浏览器完全相同。

缓存跟随域名、浏览器及其用户数据。清理站点数据、更换浏览器或更换试玩域名后会重新下载。不是将网页安装成独立 App；也不能消除第一次访问 GitHub Pages 的网络延迟。

## 音效与触摸

- 父页面按钮与拆包 iframe 共用已解锁的 AudioContext。在真实的按下、松开、触摸结束、点击和键盘事件中解锁，避免等 `postMessage` 或广告 Promise 返回后才尝试启动。
- 复用一份合成器及噪声、混响缓冲，不在每次进入拆包时重新生成。拆包保留原音量及破空层，棋盘翻牌保留原音量并继续关闭落地/破空噪声。
- 手指按住滑过卡背时播放滑牌声；超过轻触距离的滑动不当作点选。正常点击仍只免费翻一张，任选解锁后再展开剩余卡片。
- 离开拆包停止连续撕裂声；后台暂停渲染，返回后恢复。静音继续由现有游戏设置控制。

声音由 Web Audio 合成，没有外部 MP3 可供额外下载。资源缓存不能代替手机浏览器的音频解锁要求。

## 动画开销

继续使用原拆包的弹簧、封条、袋体反冲、六卡出包与环绕、32 道虹彩和翻牌。手机端保留完整运动，每约 50ms 才更新一次卡面光学样式；光流路径约每 32ms 更新一次、减少路径采样点。减少多层滤镜，不再每帧重复写相同样式与无障碍标签，也不再逐帧重建弹簧列表。

缓存解决下载等待；预解析和图片解码减少第一次使用时的停顿；滤镜和绘制优化减少运行中的持续开销。不能仅凭桌面浏览器的手机尺寸预览承诺任何手机稳定达到某个帧率。

## 网站与 TapTap 小游戏

当前分享的是普通 HTTPS 静态网站，浏览器从网站下载资源。TapTap 官方区分「H5 小游戏」与「普通小游戏」两种包体。本项目依赖 HTML/CSS、DOM 和 iframe，应走 H5 路线，将构建目录交给平台上传、分发和更新，同时接入平台身份、广告等能力。

平台上传包与 GitHub Pages 的网络路径不同，平台包缓存策略也可能不同；上传到平台不等于自动解决所有动画与音频兼容问题。Service Worker、同源 iframe、CSS 3D、Web Audio 与 WebGL 需要在 TapTap 容器真机验证。普通小游戏的无 DOM 运行环境不是当前网页直接换个上传入口即可运行的目标。

更多官方来源见 [TapTap H5 接入调研](TapTap-H5接入调研-2026-11-24.md)。本次再次核对[官方小游戏介绍](https://developer.taptap.cn/minigameapidoc/quick-start/guide/minigames-intro/)，确认两种包体的区分。尚未上传或提审 TapTap 测试包。

## 代码与验收

- `src/bootstrap.ts`：加载页、进度、预解码和降级。
- `tools/offline-build.ts`、`tools/service-worker.js`：自动清单、版本缓存、更新和离线资源响应。完整发布 `dist/`，不要遗漏生成的 `sw.js` 和 `game-assets.json`；后续新增皮肤资源会自动进入清单。
- `src/card-sounds.ts`、`src/blessing-pack.ts`、`public/prism-blessing/sound.js`：共用音频与同步解锁。
- `public/prism-blessing/engine.js`、`integration.css`：触摸、样式更新和手机绘制优化。
- `tests/asset-cache.test.ts`：首次准备、重复离线命中、嵌套目录 iframe、部分失败重试、版本切换和请求范围。已有玩法及不保存对局的测试继续保留。

开发服务跳过持久缓存，避免 Service Worker 干扰热更新。可用 `?previewBlessing=1&previewUniverse=naiwa&previewMobileEffects=1` 独立检查手机特效路径和音效调用；该开关只在开发构建有效。缓存必须使用生产构建加 HTTP/HTTPS 服务测试。

本次浏览器验证：390×844 布局、59 项资源首次缓存与再次全部命中；关闭本地测试服务器后，刷新仍可进入首页、拆包及六卡任选。独立开发预览确认撕包抓取/连续撕裂/爆开、卡背滑过与翻牌均调用音效，AudioContext 为 `running`。还需实际手机和 TapTap 容器复测扬声器输出、触摸细节与持续流畅度。
